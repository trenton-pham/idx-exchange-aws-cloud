# Week 1 Observations
## Root User
The root user is the ownership that you have across your cloud computing resources, such as billing details and cloud services. This allows the user to directly manage and administer services that an app may be using without AWS restrictions.
## IAM 
The IAM (Identity and Access Management) creates sub-users with restricted access to the services used. This category serves as a user who has access to one AWS service but not the other, allowing for organizations to delegate access and tasks across IAM users.
## Shared Responsibility Model
The Shared Responsibility Model are the responsibilities that both the cloud provider (such as AWS) and the customer holds. The customers maintains the specific services ran on the cloud, while the cloud provider maintains the global infrastructure (such as servers and data centers) that the services are ran on.
